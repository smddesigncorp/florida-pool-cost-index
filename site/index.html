Why Pool Prices Vary So Much

Pool prices cover a wide range because every project is different. A simple, small pool can start around $50,000. Adding a spa, a screen enclosure, upgraded materials, upgraded decking or water features can push the price well beyond that. The quotes here run from very basic pools to very extravagant ones, with everything in between. Use this tool to see the typical range, then compare it with what your own project includes.
